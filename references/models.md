# 模型与选型

2026-10-14 根据 GrsAI 公共目录和接口文档核对。以下是供应商调用 ID，价格单位均为原始积分。名称、价位及同名原厂型号不能证明本渠道的质量、速度、上下文或工具能力。维护状态和价格可能变化，使用前以供应商当前信息为准。

## 选型规则

先按任务类型、参考素材、透明背景、遮罩、尺寸、画幅、视频时长和 `selection.maxCredits` 筛选；任何硬条件不满足就报错。显式指定模型时保留该模型，条件不满足时不替换。自动候选是通用策略推断，不是质量排名。

| 任务 | 默认候选 | 选择依据与检查 |
|---|---|---|
| 简单文本、提取、翻译、短摘要 | gemini-3.1-flash-lite | 低成本候选，检查字段与语义 |
| 图片问答 | gemini-3.1-flash-lite | 低成本候选，接口可表达图片输入；可显式选择其他文本型号 |
| 纯文本代码、推理、复杂指令 | gpt-6.1-sol | 任务适用性推断，生成后验证结果 |
| 图片草稿 | nano-banana-2-lite | 440积分/次，不发送尺寸字段 |
| 常规1K图片、文字或图解候选 | gpt-image-2.5 | 支持1K比例或像素参数，检查文字和布局 |
| 参考图编辑、2K/4K图片 | nano-banana-2.1 | 接口支持尺寸选择，检查内容保留与实际像素 |
| 透明背景 | gpt-image-2-vip | 接口有透明参数，检查输出alpha |
| 遮罩编辑 | gpt-image-2.5或符合尺寸的VIP | 需要原图与遮罩，检查编辑区域 |
| 普通横/竖短视频 | minimax-h3 | 分辨率与时长匹配，检查动作和声音 |
| 720p/2K或具体比例视频 | agnes-video-2.5 | 按接口范围选择，检查实际画幅与时长 |

`quality` 优先级默认尝试2K图片候选，尺寸不代表画质优势。`speed` 优先级尝试低成本候选，不承诺速度更快。高成本渠道型号由用户显式选择。文字密集的海报、表格或可编辑文档宜用文本生成和确定性排版，图片模型负责底图。

Nano采用 `imageSize`，常规比例为auto、1:1、16:9、9:16、4:3、3:4、3:2、2:3、5:4、4:5、21:9；Nano 2系列增加1:4、4:1、1:8、8:1。Lite的型号在目录中存在，统一Nano文档的型号列表尚未同步此ID；其自动选择属于目录与接口适配的推断。

GPT的VIP/flare/sunburst用 `aspectRatio` 传像素字符串。VIP自定义尺寸限制为长边≤3840、双边为16的倍数、边长比≤3、总像素655360–8294400。文档列出的预设像素与自定义限制分别处理。2.5/2支持比例或1K像素；统一接口不接受 `imageSize`。4K标签不保证4096×4096，具体映射见GPT公开接口文档。

图片与聊天参考最多16张是本包保护限制，不是供应商或原厂承诺。遮罩也计入本包图片数量限制。透明/mask表示接口参数存在，成品仍需检查。
